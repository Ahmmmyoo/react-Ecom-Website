# Luma Storefront

A premium React storefront concept built with Vite and Tailwind CSS. The project presents Apple-focused devices through a more polished e-commerce experience, with curated product content, category filtering, and a refined cart summary designed to feel portfolio-ready.

## Highlights

- Premium landing experience with a branded hero, metrics, and editorial product presentation
- Category-based browsing for phones, tablets, wearables, audio, and laptops
- Interactive cart with quantity controls, shipping threshold messaging, tax estimate, and order total
- Responsive layout optimized for both desktop and mobile screens
- Cleaner project structure with reusable pricing helpers and richer product data

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES Modules)

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Project Structure

```text
src/
├── assets/         # Static brand assets
├── components/     # UI sections such as header, catalog, and cart
├── data/           # Product catalog data
├── utils/          # Shared helpers like currency formatting
├── App.jsx         # Main page composition
├── App.css         # Visual system and custom styling
└── index.css       # Tailwind layers and base overrides
```

## Notes

This project is intentionally styled as a polished showcase piece rather than a basic tutorial demo. The focus is on stronger merchandising, clearer UX, and a more professional visual system.
